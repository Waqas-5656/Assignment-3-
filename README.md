# C++ Programming Assignment 3

A collection of 11 console-based C++ programs demonstrating core programming concepts such as conditional logic (`if-else`, `switch`), loops, functions, arithmetic calculations, and user input validation across real-world scenarios.

## 📂 Repository Contents

| # | File Name | Description |
| :--- | :--- | :--- |
| 01 | `01_Electricity Bill System.cpp` | Calculates monthly electricity bills based on consumed units, slab rates, and applicable surcharges. |
| 02 | `02_Aemission System.cpp` | Evaluates student admission eligibility and processes enrollment criteria based on academic scores. |
| 03 | `03_Bank Loan.cpp` | Determines bank loan eligibility, interest rates, and monthly installment calculations. |
| 04 | `04_Hospital System.cpp` | Manages patient billing, ward charges, consultation fees, and medical service calculations. |
| 05 | `05_Traffic Fine System.cpp` | Computes traffic violation penalties and fines based on offense type and vehicle category. |
| 06 | `06_Online Shopping Discount.cpp` | Applies tiered discounts, promo rules, and final checkout pricing for online shopping carts. |
| 07 | `07_Employ Salary.cpp` | Calculates employee net salary including basic pay, allowances, bonuses, and tax deductions. |
| 08 | `08_ATM Withdrawal System.cpp` | Simulates ATM cash withdrawal operations with balance checks, daily limits, and PIN/account validation. |
| 09 | `09_Ride Hailing System.cpp` | Estimates ride fares based on distance, base fare, surge pricing, and ride type. |
| 10 | `10_Examination and Scholarship System.cpp` | Evaluates exam grades and determines student scholarship percentages based on merit criteria. |
| 11 | `11_Smart Insurance.cpp` | Calculates insurance premiums and coverage plans based on user risk factors and policy type. |
